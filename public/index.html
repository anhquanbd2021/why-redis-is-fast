Cache Lab · slow DB behind a mini Redis

"In-memory" is a third of the answer.

A simulated database pays 60 ms per query. Put a tiny Redis in front of it and watch the same read drop to microseconds — then expire a hot key and watch a naive cache stampede the database while single-flight sends exactly one query.

Safe educational demo. All simulation runs in your browser — no network calls, no real Redis, latencies are modeled not measured.
